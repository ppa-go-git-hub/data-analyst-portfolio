# Projet 6 : Optimisez la gestion des données d'une boutique avec R ou Python

Les données de cette entreprise sont mal organisées. Faites cohabiter les différents jeux de données pour effectuer l'analyse demandée

## Qu'allez-vous apprendre dans ce projet ?

Dans les projets précédents, vous avez acquis des compétences fondamentales en collecte et traitement des données.

Dans ce projet, vous allez approfondir vos compétences dans le traitement et le nettoyage des données du stock d'une boutique :
- vous utiliserez des librairies ;
- effectuerez des analyses exploratoires de fichiers ;
- travaillerez avec un notebook ;
- effectuerez des jonctions de fichiers ;
- des analyses univariées ;
- et terminerez par la présentation de votre travail. 

## En quoi ces compétences sont-elles importantes pour votre carrière ?

Ces compétences sont fondamentales pour un Data Analyst : la préparation des données pour l'analyse constitue une part importante de votre future carrière.
Il est donc nécessaire de vous entraîner. 

## Objectifs pédagogiques

- Effectuer des analyses univariées et multivariées des données pré-traitées
- Pré-traiter des données pour explorer et comprendre leurs caractéristiques
- Traiter, nettoyer des données et définir la gestion des incohérences en conformité du RGPD
