# Projet 5 : Créez et utilisez une base de données immobilière avec SQL

À partir des données de votre agence immobilière, concevez et créez une base de données, puis faites des requêtes SQL pour extraire certaines données en respect du RGPD

## Qu'allez-vous apprendre dans ce projet ?

Vous allez apprendre à concevoir un **schéma relationnel** respectant la **troisième forme normale (3NF)**.
Vous mettrez en pratique la création de **tables SQL**, l'import de **données CSV** et la gestion de contraintes.
Vous découvrirez aussi les concepts de **dictionnaire de données** et de **conformité RGPD**.

## En quoi ces compétences sont-elles importantes pour votre carrière ?

Ces compétences sont essentielles pour tout poste d'analyste ou de développeur. 

La capacité à **créer, modéliser et interroger** une base de données est un **pré-requis incontournable** sur le marché de l'emploi.

Les recruteurs recherchent des profils capables de manipuler des données brutes pour en extraire des indicateurs exploitables.

La maîtrise de SQL et des modèles relationnels vous permettra de travailler efficacement dans des environnements data réels.

La capacité à justifier d'une méthodologie de travail rigoureuse, incluant l'usage responsable de l'intelligence artificielle, renforcera votre posture de consultant ou d'analyste.

## Comment allez-vous procéder ?

- **Cours** : Vous suivrez les cours liés à ce projet.
- **Mission : Créez la base de données** 
    - Dans cette première mission, vous analyserez les données pour extraire les variables clés. Vous mettrez à jour le schéma relationnel pour l'aligner aux nouvelles données, puis vous créerez la BDD.
- **Mission : Remplissez et interrogez la base de données**
    - Dans cette seconde mission, vous vous exercerez à importer les données nettoyées dans la base de données que vous avez conçue, en respectant les types, contraintes et relations entre tables.
    - Vous rédigerez ensuite une série de requêtes SQL permettant d'analyser le marché immobilier : indicateurs clés, segmentations régionales, comparaisons, etc.
- Vous terminerez en complétant la fiche d'autoévaluation qui servira de base de discussion avec votre mentor avant la soutenance.

À l'issue de ce projet, vous présenterez les livrables de la mission à un mentor évaluateur lors d'une **soutenance**.

Cela vous permettra de valider les compétences visées par ce projet.

## Objectifs pédagogiques

- Créer une base de données en respect des normes réglementaires et des besoins clients
- Effectuer des requêtes SQL pour répondre à une problématique métier en respect du RGPD
- Gérer une base de données établissant des requêtes et en respect du RGPD
