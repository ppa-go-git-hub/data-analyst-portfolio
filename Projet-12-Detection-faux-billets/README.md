# Projet 12 : Détectez des faux billets avec R ou Python

Construisez un modèle de prédiction pour détecter des faux billets grâce à du clustering et de la régression logistique avec R ou Python

## Qu'allez-vous apprendre dans ce projet ?

À partir d'un jeu de données réel sur les dimensions de vrais et faux billets, vous allez :

- Explorer et visualiser les données
- Préparer et nettoyer le jeu de données
- Construire et comparer plusieurs modèles de classification
- Évaluer leurs performances et choisir le plus efficace
- Identifier les critères qui permettent de repérer un faux billet
- Présenter clairement vos résultats et votre modèle

Ce projet vous permet de mobiliser toutes vos compétences d'analyste tout en réalisant votre première mission complète de modélisation prédictive.
C'est un excellent tremplin vers la data science et une réalisation concrète à mettre dans votre portfolio !

## En quoi ces compétences sont-elles importantes pour votre carrière ?  

L'analyse de données et la présentation des résultats sont des compétences primordiales pour un data analyst.

## Comment allez-vous procéder ?

Vous réaliserez la mission principale et vous terminerez en complétant la fiche d'autoévaluation qui servira de base de discussion avec votre mentor avant la soutenance.

Vous présenterez les livrables de la mission à un mentor évaluateur lors d'une soutenance.

Cela vous permettra de valider les compétences visées par ce projet. 

## Objectifs pédagogiques

- Utiliser un modèle d'apprentissage supervisé pour réaliser une prédiction d'un phénomène
- Entraîner un modèle d'apprentissage non supervisé pour exploiter le modèle
