# Projet 3 : Requêtez une base de données avec SQL

Aidez une entreprise de l'assurance à mieux accompagner ses clients en analysant le marché des assurances habitation

## Qu'allez-vous apprendre dans ce projet ? 

Ce projet a pour but de vous faire découvrir la **création** et la **gestion de bases de données**.
Il est très guidé et vous accompagne étape par étape dans l'acquisition des fondamentaux du métier.
Son format est différent des projets scénarisés : il s'agit **d'exercices d'entraînement**.

## En quoi ces compétences sont-elles importantes pour votre carrière ?

Vous exécuterez régulièrement ces activités en tant que data analyst ou business intelligence analyst.
La création et la gestion de bases de données sont incontournables dans les métiers de l'analyse de données. 

Ce projet vous prépare à la suite de votre parcours et notamment à des projets plus poussés dans lesquels vous approfondirez votre connaissance du requêtage SQL.   

## Comment allez-vous procéder ?

Ce projet est découpé en 2 activités.

- Cours : Vous suivrez le cours "Développez votre culture des données" pour vous permettre de comprendre les enjeux de la gestion des données. 
- Exercice : 
    - Vous vous exercerez à créer et requêter une base de données.
    - Vous terminerez en complétant la fiche d'autoévaluation qui servira de base de discussion et de bilan avec votre mentor.

À l'issue de ce projet, vous aurez une **session de bilan** avec votre mentor pour discuter de votre projet.

Cela vous assurera que vous êtes sur la bonne voie avant de passer à la suite. 

## Objectifs pédagogiques

- Charger des données dans une base de données
- Créer un schéma d'une base de données
- Rédiger des scripts simples en SQL pour aider à la prise de décision business
