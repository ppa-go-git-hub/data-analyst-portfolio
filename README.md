## 👨‍💻 Compétences clés

- Collecter, explorer, nettoyer et transformer des données brutes en insights dans le respect du RGPD
- Modéliser, implémenter, mettre à jour et interroger les bases de données
- Communiquer : choix des graphiques, outils de visualisation, maximisation de l'impact (storytelling)

## 📁 Résumé des projets

Voici une synthèse des projets réalisés au cours de la formation.
Les liens vous emmènent vers un sous-dossier dédié à chaque projet, où vous retrouverez une présentation plus détaillée du contexte, ainsi que les livrables techniques et les supports de présentation.

1. [Prenez en main votre formation de Data Analyst](Projet-01-Soft-skills)

    - Identifier les soft skills propres au métier de Data Analyst
    - Adopter la posture d'un Data Analyst

2. [Faites une analyse de ventes pour un e-commerce avec Excel](Projet-02-Analyse-ventes-commerce)

    - Concevoir des graphiques adaptés en prenant en compte les bonnes pratiques d'accessibilité
    - Proposer un récit des résultats avec des procédés narratifs pour dynamiser la présentation

3. [Requêtez une base de données avec SQL](Projet-03-SQL-Assurance)

    - Charger des données dans une base de données
    - Créer un schéma d'une base de données
    - Rédiger des scripts simples en SQL pour aider à la prise de décision business

4. [Réalisez une étude de santé publique avec Python](Projet-04-Etude-sante-publique)

    - Explorer et analyser des données en utilisant des langages et outils métiers

5. [Créez et utilisez une base de données immobilière avec SQL](Projet-05-SQL-Immobilier)

    - Créer une base de données en respect des normes réglementaires et des besoins clients
    - Effectuer des requêtes SQL pour répondre à une problématique métier en respect du RGPD
    - Gérer une base de données établissant des requêtes et en respect du RGPD

6. [Optimisez la gestion des données d'une boutique avec Python](Projet-06-Optimisation-donnees-boutique)

    - Effectuer des analyses univariées et multivariées des données pré-traitées
    - Pré-traiter des données pour explorer et comprendre leurs caractéristiques
    - Traiter, nettoyer des données et définir la gestion des incohérences en conformité du RGPD

7. [Créez un tableau de bord dynamique pour visualiser l'avancement de projets avec Power BI](Projet-07-Dashboard-avancement-projets)

    - Produire un reporting en analysant les visualisations pour faciliter les décisions

8. [Analysez l'évolution de profils sociodémographiques avec DBT](Projet-08-Analyse-evolution-profils-sociodemographiques)

    - Agréger des extractions de données en définissant les règles de nettoyage
    - Collecter des données pertinentes en respect des normes et bonnes pratiques
    - Vérifier la cohérence et la fiabilité des données préparées

9. [Analysez les ventes d'une librairie avec Python](Projet-09-Analyse-ventes-librairie)

    - Analyser un jeu de données avec séries temporelles pour mesurer un phénomène statistique
    - Réaliser des tests statistiques sur des données afin de tester et valider des hypothèses

10. [Faites une étude sur l'eau potable avec Python et Power BI](Projet-10-Dashboard-etude-eau-potable)

    - Proposer un récit des résultats dynamique pour engager un public
    - Optimiser une solution de visualisation accessible, adaptée au public et au type de donnée
    - Créer un tableau de bord interactif pour rendre la visualisation disponible et accessible

11. [Produisez une étude de marché avec Python](Projet-11-Etude-marche)

    - Exploiter un modèle d'apprentissage afin d'en apprendre davantage sur les données
    - Réaliser des analyses multivariées pour comprendre la corrélation entre les variables
    - Réduire la dimension du jeu de données pour optimiser le temps d'apprentissage des modèles
    - Sélectionner les variables pertinentes d'un modèle d'apprentissage

12. [Détectez des faux billets avec Python](Projet-12-Detection-faux-billets)

    - Utiliser un modèle d'apprentissage supervisé pour réaliser une prédiction d'un phénomène
    - Entraîner un modèle d'apprentissage non supervisé pour exploiter le modèle

13. [Pilotez un projet data augmenté avec l'IA et créez votre portfolio de professionnel](Projet-13-Pilotage-IA)

    - Accompagner les équipes sur la prise en main des outils
    - Adapter sa posture de professionnel en se positionnant comme consultant
    - Effectuer une veille métier et technologique
    - Expérimenter de nouvelles méthodes d'analyse de données à travers des recherches
    - Formaliser les procédures de documentation pour assurer une gestion fiable
    - Formaliser un cahier des charges fonctionnel pour cadrer les besoins et les solutions
    - Identifier les besoins métier en intégrant les différentes contraintes
    - Organiser un projet d'analyse data grâce à des outils de gestion de projet
